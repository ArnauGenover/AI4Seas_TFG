Important: Using Gmail with Ship Broker

For security reasons, Gmail requires you to use an "App Password" instead of your regular password:

  1. Go to your Google Account settings
  2. Enable 2-Step Verification if not already enabled
  3. Go to Security → App passwords
  4. Select "Mail" and your device/app
  5. Generate a new app password
  6. Use that generated password in the "Email Password" field below
This app password will only work with the Ship Broker application and is safer than using your main password.

Outlook/Hotmail:

  1. Go to your Microsoft account's Security settings
  2. Create an "App Password" specifically for this application
  3. Use that password in the "Email Password" field below

Yahoo Mail:

  1. Go to your Yahoo Account security page
  2. Enable "2-step verification" if not already enabled
  3. Click "Generate app password"
  4. Use that password in the "Email Password" field below
